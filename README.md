# stm32‑thd‑distortion‑meter
基于 STM32F407 的便携式总谐波失真度(THD)测量装置，电赛作品。
片内ADC + DMA采集，实现自研基2‑FFT频谱分析；支持OLED本地显示、JDY‑31蓝牙SPP透传至手机APP，一键测量，3秒内输出结果。

## 📋项目简介
本装置用于测量正弦信号的总谐波失真度THD，输入信号经过INA828仪表放大器完成信号放大与直流电平抬升，STM32利用定时器触发DMA完成1024点高速采样。
软件实现去直流、汉宁窗加窗、基2迭代FFT、主瓣能量求和、多帧功率谱平均降噪；发挥部分采用两遍自适应采样率，测量频率覆盖 **500 Hz ~ 50 kHz**。

测量输出：THD总谐波失真、基波频率、2‑5次谐波幅值、单周期波形。
数据可在 SH1106‑OLED(128×64)本地显示，同时通过JDY‑31经典蓝牙透传到手机APP查看。整机USB5V供电，一键启动测量。

## ⚙硬件平台
- 主控芯片：STM32F407ZGT6
- 信号调理：INA828 仪表放大器（单电源5V，增益≈4.5倍，REF引脚叠加1.65V直流偏置）
- ADC：片内12bit ADC1，TIM3硬件触发，DMA2完成数据搬运
- 显示：SH1106 OLED 128×64，软件I2C
- 蓝牙模块：JDY‑31（SPP串口透传，波特率9600，配对码：1234）
- 按键：PA0 一键测量触发

### 📌引脚分配
|外设|引脚|功能说明|
|---|---|---|
|信号输入|PA1|ADC1_IN1，调理电路输出|
|OLED I2C|PB6 / PB7|SCL / SDA，器件地址0x3C|
|调试串口|PA9 / PA10|USART1 115200，CH340连接PC|
|JDY‑31蓝牙|PA2 / PA3|USART2 9600，SPP透传|
|启动按键|PA0|测量触发按键|

> 本项目仅使用STM32片内ADC，无外部ADC采集芯片。

## 🧮核心算法
1. **硬件同步采样**：TIM3定时器触发ADC，保证采样间隔严格均匀，不使用软件延时。
2. **去直流**：计算采样帧均值，去除输入叠加的直流偏置，提取纯交流信号。
3. **相干采样**：基础档1kHz配置采样率，让基波、谐波落在FFT整数频点，从根源抑制频谱泄漏。
4. **汉宁窗 + 主瓣能量求和**：对频点峰值±2 bin做能量累加，解决非相干采样下幅值计算偏低的问题。
5. **自研迭代基2‑FFT**：N=1024点，位反转+蝶形运算，无第三方FFT库，便于调试阅读。
6. **汉宁窗比值法**：对基波频率进行精细修正，提升频率测量精度。
7. **多帧功率谱平均降噪**：16帧功率谱累加平均，降低本底噪声，改善小信号测量性能；仅平均功率谱，**不做时域平均**避免信号抵消。
8. **发挥部分‑两遍自适应采样率**
    - Pass1粗测：固定150kHz采样率，估算输入信号基频；
    - Pass2精测：自动计算最优采样率，尽可能实现相干采样，汉宁窗算法兜底；
    - 实现测量带宽：`500Hz ~ 50kHz`
9. **波形绘制**：过零点检测定位波形起点，线性插值，在OLED屏幕绘制一个周期的自适应缩放波形。
